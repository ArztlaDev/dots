# My Personal Arch Linux + Hyprland Dotfiles

Личная сборка дотфайлов для **Arch Linux** и композитного менеджера **Hyprland**. Проект предназначен исключительно для индивидуального использования, **не привязан к Git-репозиторию** (устанавливается вручную) и **не будет поддерживаться** в будущем.

## 🛠 Зависимости

Перед копированием конфигурационных файлов необходимо установить следующие пакеты:

### Основные компоненты
* `hyprland` — композитный менеджер
* `waybar-git` — статус-бар (AUR-версия)
* `sddm` — дисплейный менеджер
* `dolphin` — файловый менеджер
* `qt6-*` — все библиотеки QT6 для корректного отображения интерфейса

### Утилиты и интерфейс
* `rofi` — меню запуска приложений и превью окон
* `swaync` — центр уведомлений
* `awww` — обои рабочего стола
* `hyprpolkit` — агент аутентификации
* `nwg-displays` — управление мониторами
* `nwg-look` — настройка GTK-темы
* `cliphist` — менеджер истории буфера обмена (опционально)
* `wl-clipboard` — утилита для работы с буфером обмена Wayland (опционально)

### Шрифты (обязательно для иконок и текста статус-бара)
* `otf-font-awesome` — стандартные иконки для Waybar
* `ttf-jetbrainsmono-nerd` — основной шрифт конфигурации

## 🎨 Темы, иконки и сторонние конфигурации

Для полноценного внешнего вида и функционала сборки используются сторонние ресурсы. Их необходимо скачать и настроить вручную:

* **Иконки:** [Pixora Icons](https://github.com)
* **Тема SDDM:** [SDDM Astronaut Theme](https://github.com)
* **Базовая конфигурация Waybar:** В основу статус-бара сборка [my-waybar-config от a4x7](https://github.com), слегка настроил её под себя,
* все возможности этого бара ищите в его конфигах!

## 🚀 Установка

Поскольку дотфайлы не автоматизированы скриптами, перенос файлов в домашнюю директорию выполняется вручную.

1. Установите все пакеты из списка зависимостей через `pacman` и ваш AUR-помощник (например, `yay` или `paru`).
2. Установите иконки Pixora, можно через внутренний скрипт.
3. Распакуйте тему SDDM Astronaut в `/usr/share/sddm/themes/` и активируйте её в `/etc/sddm.conf`(тоже есть скрипт в репо автора).
4. Скопируйте конфигурационные папки в директорию `~/.config/`:
   ```bash
   cp -r ./hypr ./waybar ./rofi ./swaync ~/.config/
   ```

## ⚠️ Отказ от ответственности

Сборка создана "как есть" для личного использования. Поддержка не планируется.
Запускать скрипты из интернета без проверки не лучшая идея.
Подумайте трижды нужно ли оно вам.
В сборке все еще присутствует много проблем(возможно будут исправлены).
В сборке частично присутствует вайбкод из-за моей лени.
